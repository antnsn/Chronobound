# Commands

Everything in Chronobound can be set in the options window (`/cb`). These chat commands are shortcuts.

`/chronobound` works everywhere `/cb` does. Commands only do something on a mage.

## Windows

| Command | What it does |
| --- | --- |
| `/cb` | Opens or closes the options window. `/cb options` and `/cb config` do the same. |
| `/cb help` | Lists every command in chat. |

## Frames

| Command | What it does |
| --- | --- |
| `/cb unlock` | Unlocks all frames so you can drag and resize them. See [Quality of life](features/quality-of-life.html#moving-and-resizing-frames). |
| `/cb lock` | Locks the frames again. |
| `/cb move` | Unlocks the frames, or locks them if they are unlocked. |
| `/cb reset` | Puts every frame back in its default place and size. |
| `/cb grid` | Turns snapping to the grid on or off. |
| `/cb grid 30` | Sets the grid size (4 to 100) and turns snapping on. |
| `/cb minimap` | Shows or hides the minimap button. |

## Explanations

| Command | What it does |
| --- | --- |
| `/cb explain` | Turns the [explanations](features/explanations.html) in tooltips on or off. |

Every command also works without the space, for example `/cbunlock` or `/cbhelp`. That helps when a chat addon swallows the Enter key after a space.

Type anything else after `/cb` to get the list of commands in chat.

The [buff key](features/buff-key.html) is not a command: set it on the **Extras** page of `/cb`.
